# Golden Fleece ACDE Website

Initial website and development environment for **Golden Fleece ACDE**.

Current scope: a landing page for the first product, **construction takeoff**, focused on returning accurate material requirements from any blueprint set.

## Tech stack

- React 19
- TypeScript
- Vite

## Local development

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Available scripts

- `npm run dev` - start development server
- `npm run build` - production build
- `npm run preview` - preview production build
- `npm run lint` - lint source code
